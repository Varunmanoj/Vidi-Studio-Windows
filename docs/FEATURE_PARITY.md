## Existing assets, provenance, and Markdown summary (1.0.176)

Windows mirrors the Mac contract: New Project existing assets and Project → Import Existing Assets…, SRT/VTT/TXT transcripts and AD transcripts, Markdown/TXT summaries, WAV/MP3/M4A/AAC/FLAC AD audio, AD narration-only versus combined caption mode, narration-only versus full AD mix, TXT timing review, Create Project & Combine, two switchable tracks with Closed as the default and Open as an explicit single mix, import validation reports and overlap blocking, per-segment narration import, six provenance labels, AD Overview narration sources, and the Markdown summary toolbar/shortcuts. Windows 11 ARM64 Release packaging and x64 Debug builds pass; native ARM64 and x64 suites pass with the bundled engine, actual imports, two-track audio combination, Markdown formatting/undo/save/readback, and external-folder persistence. The Help book can be regenerated from Mac sources with script/sync_windows_help.py. Full Narrator, Windows 10, macOS runtime, and live Gemini checks remain separate.

## AI availability and key-free project creation (1.0.152)

Project creation and existing-asset imports do not require a Gemini key; the YouTube Gemini access check runs only when a key is configured. Quota, credit/billing, permission, and service failures set a persistent AI issue, disable all AI reprocessing, and show a Retry AI warning. Existing transcripts, descriptions, narration, and exports remain unchanged. Native Windows build and runtime validation still require a Windows host.


## Windows parity repair validation (1.0.176)

Compared against Mac source 7069d59 and its current working tree. The import engine matches Mac's AST; 53 shared export/progress functions, media formats, and ducking match. Windows now uses Mac's three-attempt YouTube download policy with 2/4-second backoff while preserving classified worker errors and cancellation markers. The exact reviewed downloader snapshots remain enforced by check-mac-export-parity.py.

The Summary editor yields Ctrl-Alt-1/2 to local heading commands, preserves native undo for formatting, keeps blank lines and list indentation, ends empty numbered items, and routes confirmed saves through the locked engine with provenance updates. The reader handles strikethrough, underscore emphasis, image alt links, and soft paragraph breaks; speech uses the same plain text. SRT/VTT review opens correctly, timing refresh no longer overwrites edits, import failures stop the remaining commands, and reports open the appropriate Transcript or Descriptions section.


## Reported presentation regressions (1.0.177)

Legacy summaries containing repeated leading U+FEFF marks now render their first heading correctly without rewriting the project on open; future saves clean the marks through the shared engine. The Help TOC binds through TreeViewNode.Content and is validated using actual visible chapter/topic labels in light/dark mode. Help initial sizing respects monitor DPI, and only the current chapter starts expanded. Both native target suites pass with the user's real summary copied into an isolated fixture. See PROGRESS.md for installation evidence and the correction to the earlier data-only TOC assertion.


## Editor sections and Summary source (1.0.178)

Windows matches Mac's five editor sections. Created Exports is available in the inspector rather than the section selector. A Summary source badge remains visible in reading mode and uses the same origin glyph/color mapping as the icon-bearing edit-mode choices. ARM64 native checks cover AI-generated, Imported, Manually added, and Origin unknown without entering edit mode.
