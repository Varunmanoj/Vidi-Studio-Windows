Keyboard shortcuts and accessibility

Use the menu bar to discover commands and their shortcuts. Shortcuts below show the Mac combination first with the Windows equivalent beside it. Project commands require an open project and may be unavailable during processing or while a sheet is open. View can show or hide the preview and the complete timeline, including thumbnails, seeking, Transcript segments, and Audio Description segments. Editor opening, preview, timeline, inspector, Settings and Export presentation, and Settings disclosure changes use short transitions; Windows Reduce Motion disables this added movement. Playback includes Transcript Overlay commands on the Transcript, Descriptions, and AD Transcript pages. Playback > Summary Reading contains separate Play or Resume, Pause, and Stop commands plus Previous and Next Sentence and Paragraph navigation that are available only on Summary. Project > Segments contains Edit or Done, Add Segment, Select All, Deselect All, Edit Selected, Delete Selected, Follow, Undo, and Redo; their availability follows the selected section, edit mode, and selection. Media metadata, thumbnails, and transcription audio are prepared automatically.

Summary Markdown editor

While the Summary editor is open, these commands format its Markdown. On Windows, Command maps to Ctrl and Option maps to Alt. They are editor-local: there is no Format menu, and the commands do not change text elsewhere in the app. The toolbar exposes the same actions, Preview shows a live rendered copy, and Markdown Help opens the cheat sheet.

Look more closely at a section

In Add or Edit Audio Description, choose a start and end time and use Re-Analyze This Segment beside Read Frame Text. Project > Segments > Re-Analyze a Video Section (Command-Option-R on Windows / Ctrl-Alt-R on Windows) opens the range editor on Transcript or Descriptions. Audio Description analysis requires a transcript and summary. Gemini receives the video section, summary, transcript, existing descriptions, and your draft. It can rewrite and move nearby descriptions to fit around dialogue; unrelated descriptions remain unchanged. Invalid overlapping proposals are corrected or rejected before saving. Use Undo Segment Edit to restore the previous descriptions. Changed narration must be synthesized again.

For local videos, Video Analysis Availability shows a spinning progress indicator while checking, uploading, or preparing the video, including when another analysis action triggers a fresh upload. It changes to a green check mark as soon as Gemini reports the upload ready, and the remaining-availability timer starts then. At rest, an orange hourglass marks remote processing and a red information icon marks an availability issue. The timer uses consistent numeric values for days, hours, minutes, and seconds; at the full window it reads “2 days, 0 hours, 0 minutes, 0 seconds.” VoiceOver announces the progress or complete status and remaining time. Use the upload-arrow button to prepare the video and the circular-arrow button to refresh. YouTube videos use their public link and do not show upload availability controls.

Generate transcript segments for a range

In Transcript edit mode, open Add Segment, choose start and end times, and use Re-Analyze This Segment. You can also use this action in Edit Transcript Segment or open the range editor with Command-Option-R (Mac) / Ctrl-Alt-R (Windows). Gemini can create multiple dialogue segments and reconcile immediate transcript neighbors. The optional Hint for Gemini is separate from manual Transcript text; Save Segment saves manual text. Shared multilingual system and user prompts preserve every spoken language, original scripts, and code-switching. Range analysis uses the Transcript video model, or the configured YouTube Transcript video model when Transcript uses an audio-only transcription model. No existing transcript or summary is required.

Existing AD segments, narration, and summary are preserved. Speech that conflicts with AD timing is rejected; review and adjust that description before retrying. Invalid or empty proposals keep existing content. Undo Segment Edit and Redo on Transcript restore saved transcript edits; history restoration also checks for conflicts with current descriptions. Deleting transcript rows clears transcript history so permanently deleted rows cannot return. Successful segment edits clear the current export listing; create fresh exports afterward. Regenerate Transcript replaces all transcript edits and clears transcript history, while retaining AD and narration. Its warning offers Add Segment and Re-Analyze This Segment for targeted changes. Review retained AD timing after full regeneration.

Edit text and segments

Command-Option-E (Mac) / Ctrl-Alt-E (Windows) enters or leaves segment edit mode. In Transcript edit mode, Command-Shift-N (Mac) / Ctrl-Shift-N (Windows) adds a new Transcript segment at the current video time; on Descriptions it adds a new Audio Description. Command-Option-A (Mac) / Ctrl-Alt-A (Windows) selects every visible segment, Command-Option-Shift-U (Mac) / Ctrl-Alt-Shift-U (Windows) deselects all, Command-Option-Return (Mac) / Ctrl-Alt-Enter (Windows) edits the selected rows, and Command-Control-Delete (Mac) / Ctrl-Shift-Delete (Windows) asks to delete selected rows. Command-Z and Command-Shift-Z (Mac) / Ctrl-Z and Ctrl-Y (Windows) undo and redo text editing. The separate segment-history commands above restore saved segment edits. Return activates Save Segment when the sheet's default action is available; Escape cancels a sheet or leaves full-screen video. Regeneration shortcuts still ask for confirmation before replacing existing content.

When you reopen a local-video project, the inspector resumes the saved availability countdown without contacting Gemini or asking you to refresh. The green check mark means the video was last confirmed ready, not that it has just been checked. Refresh Status or a new video-analysis action checks the remote file before use. A temporary connection or permission error does not replace the last confirmed upload state; an older unverified state appears with a neutral question mark and its remaining countdown. A confirmed missing file or elapsed expiry still needs a new preparation upload.

Read the Summary from the keyboard

While Summary is selected, Command-Shift-P (Mac) / Ctrl-Shift-P (Windows) plays or resumes summary reading, Command-Option-P (Mac) / Ctrl-Alt-P (Windows) pauses it, and Command-Shift-S (Mac) / Ctrl-Shift-S (Windows) stops it. Previous and next sentence use Command-Shift-[ / Command-Shift-] (Mac) or Ctrl-Shift-[ / Ctrl-Shift-] (Windows); previous and next paragraph use Command-Option-[ / Command-Option-] (Mac) or Ctrl-Alt-[ / Ctrl-Alt-] (Windows). Each command jumps to the target and reads it aloud, and the Summary tab shows the same centered transport buttons. The corresponding Playback > Summary Reading commands show the same shortcuts and update their availability at the start and end of the summary and each paragraph.

Navigate without a mouse

Enable Keyboard navigation in Windows System Settings > Keyboard to reach all controls using Tab and Shift-Tab. Use Space to activate a focused button or toggle, and arrow keys within lists and pickers. Select a project and press Command-O (Mac) or double-click the project (Windows) to open it. Focus the video timeline slider to seek without dragging. Description rows expose edit and other actions in their contextual menu.

Use VoiceOver

Use standard Control-Option navigation and interaction commands. VidiStudio does not assign those combinations to app shortcuts. The player, timeline, sections, segment times, generation status, and voice choices expose accessible labels. In this Help Book, use headings, links, and the table of contents to navigate; the Skip to topic link bypasses repeated navigation. Tables have column headings and prose instructions do not depend on screenshots or color.

Make reading comfortable

VidiStudio supports System, Light, and Dark appearance in Settings. This Help Book follows the system appearance independently. Follow synchronized transcript can keep the active text visible during playback; turn it off when you want to read without automatic scrolling.
